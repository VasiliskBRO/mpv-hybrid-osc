# mpv-hybrid-osc

Оболочка (панель управления) для видеоплеера [mpv](https://mpv.io): внешний вид
[ModernZ](https://github.com/Samillion/ModernZ) и удобные фишки [uosc](https://github.com/tomasklaen/uosc)
в одном скрипте, на русском языке. Сделана для Windows, но скрипт кроссплатформенный.

![Панель](docs/panel.jpg)

## Что умеет

- **Панель как у ModernZ:** название файла и глава, полоса перемотки с главами и превью кадров
  ([thumbfast](https://github.com/po5/thumbfast)), под ней кнопки:
  меню, субтитры, время · назад 10 с, пауза, вперёд 10 с · линейка скорости, перемешать, повтор,
  плейлист, картинка в картинке, полный экран. Кнопки «предыдущее/следующее видео» появляются,
  когда в плейлисте больше одного файла.
- **Громкость как в uosc:** вертикальный ползунок у края экрана — появляется при приближении мыши
  и при изменении громкости; колесо мыши над видео меняет громкость.
- **Линейка скорости как в uosc:** колесо, перетаскивание, правый клик — 1×. Ширина — `speed_ruler_width`.
- **Качество стримов и онлайн-видео** (меню → «Качество» или `Alt+Q`): Twitch/Kick-каналы
  открываются через [streamlink](https://streamlink.github.io/) (реклама Твича вырезается), качество
  меняется в том же окне; записи и ролики (Twitch VOD, YouTube через yt-dlp) перезапускаются
  в выбранном качестве с того же места. Скрипт `scripts/stream-quality.lua`, для эфиров нужен streamlink.
- **Вспышка паузы** по центру экрана и **индикатор загрузки** с процентом.
- **Меню как в uosc** (правый клик): открыть файл, недавние, плейлист, главы, субтитры (размер,
  сдвиг, вторые субтитры, загрузка из файла), аудиодорожки, скорость, соотношение сторон, повтор
  (в т.ч. отрезка A–B), аудиоустройство, скриншот. Поиск — просто начни печатать.
- **«Продолжено с 12:34 · С начала»** — плашка при открытии недосмотренного видео.
- **Клик по видео — пауза**, двойной клик — полный экран (перетаскивание окна не мешает).
- **Картинка в картинке** — маленькое окно поверх всех в углу экрана.
- **SponsorBlock** — пропуск рекламы в YouTube-видео, отрезки подсвечены на полосе.
- **Темы:** orange, blue, purple, green, red, pink.
- Запоминает громкость и скорость между запусками.

## Установка

Нужен mpv 0.40 или новее (проверено на 0.41). Для SponsorBlock — Python.

1. Скачай репозиторий (зелёная кнопка **Code → Download ZIP**) и распакуй.
2. Положи содержимое в папку настроек mpv:
   - Windows: `%APPDATA%\mpv\` или `portable_config\` рядом с `mpv.exe`;
   - Linux/macOS: `~/.config/mpv/`.

   Или запускай с отдельной папкой: `mpv --config-dir="путь\к\папке" видео.mkv`.
3. Если стоят другие оболочки (uosc, ModernZ и т.п.) — убери их скрипты из папки `scripts`,
   иначе будут две панели сразу. На Windows сборки mpv читают настройки ещё и из папки рядом
   с `mpv.exe` — проверь и её.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Правый клик, `Menu` | главное меню |
| Клик / двойной клик | пауза / полный экран |
| `Ctrl+O` | открыть файл |
| `Ctrl+H` | недавние файлы |
| `Alt+S`, `Alt+A`, `Alt+P`, `Alt+C` | субтитры, аудио, плейлист, главы |
| `Alt+D` | аудиоустройство |
| `Ctrl+P` | картинка в картинке |
| `Alt+Q` | качество стрима / онлайн-видео |
| `Ctrl+E` | редактор оболочки |
| `←` `→` / `↑` `↓` / колесо | перемотка 5 с / громкость |

Основные клавиши продублированы для русской раскладки. Все привязки — в `input.conf`.

## Редактор оболочки и скины

Панель можно перестроить мышкой, без правки файлов: `Ctrl+E` или меню → «Редактор оболочки».

- **Тащи** элемент — переезжает, **за уголок** — меняется размер, ручка «высота фона» — высота
  тёмной подложки. Стрелки двигают выбранный элемент на 1 px (с Shift — на 10), `Tab` — следующий,
  `Delete` — убрать, `Ctrl+Z` — шаг назад, `Ctrl+S` — сохранить.
- **Правый клик по элементу — свойства:** что делают левая/правая кнопка и колесо (список действий
  на русском или своя команда mpv), размер, цвет, прозрачность, что прятать первым в узком окне,
  подсказка при наведении, растянуть на всю ширину, поставить по центру.
- **«Создать объект»:** готовые кнопки (скриншот, громкость, скорость 1.5×, ±30 с, главы, поверх
  окон, качество стрима…), своя кнопка с иконкой из списка, надпись, встроенные элементы.
- Положение считается от левого края, центра или правого края окна (выбирается само по тому,
  куда поставил), поэтому панель правильно растягивается при любом размере окна. Если в узком окне
  кнопки начинают налезать друг на друга, менее важные прячутся.

**Скины** — меню → «Скины»: переключение, «Новый скин (копия текущего)», переименование, удаление
(файл переносится в `skins/archive`). Скины лежат в `skins/*.json`, выбранный запоминается.
«Классическая раскладка» — прежняя панель, которая настраивается кнопками в `hybrid.conf`.

## Настройка

Всё в `script-opts/hybrid.conf` (с комментариями): какие кнопки показывать, тема, шаг скорости
и громкости, где громкость (справа/слева), вид значка паузы, размер окна «картинки в картинке» и т.д.
Полный список параметров — в начале `scripts/hybrid/main.lua` (таблица `user_opts`).
