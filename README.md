**Prism** — это красивая панель в стиле [ModernZ](https://github.com/Samillion/ModernZ) с удобными фишками
[uosc](https://github.com/tomasklaen/uosc) и встроенным **редактором**: двигай кнопки, меняй их размер,
цвет и действия, добавляй свои — без блокнота и без кода. Держи несколько скинов и переключай их в меню.

## 🚀 Установка за 3 шага

1. **Скачай** архив: [Download ZIP](https://github.com/VasiliskBRO/mpv-prism/archive/refs/heads/master.zip) и распакуй.
2. **Положи содержимое** в папку настроек mpv:
   - Windows — `portable_config` рядом с `mpv.exe` или `%APPDATA%\mpv\`;
   - Linux / macOS — `~/.config/mpv/`.
3. **Убери другие оболочки** (uosc, ModernZ и т.п.) из папки `scripts`, иначе будет две панели сразу.

Нужен **mpv 0.40+** (проверено на 0.41). По желанию: **Python** — для SponsorBlock,
**[streamlink](https://streamlink.github.io/)** — для эфиров Twitch/Kick,
**[yt-dlp](https://github.com/yt-dlp/yt-dlp)** — для видео по ссылке.

## 🎮 Быстрый старт

| Хочу | Что сделать |
|---|---|
| открыть меню | правый клик по видео |
| передвинуть кнопку, поменять цвет | `Ctrl+E` → тащи мышкой, правый клик — свойства → «Сохранить» |
| добавить свою кнопку | `Ctrl+E` → «Создать объект» |
| кнопка, которая появляется сама по себе | `Ctrl+E` → «Создать объект» → «Зона наведения», у кнопки «Появляется в зоне» |
| другой дизайн панели | меню → «Скины»: «Стандарт», «Капсула», «Кино», «Неон Prism», «Островки», «Мини», «Мобильный», «VHS», «Боковая панель», «Терминал» |
| другой вариант панели | меню → «Скины» → «Новый скин» (копия) или «Пустой скин» (с нуля) |
| сменить качество стрима | `Alt+Q` |
| вернуть всё как было | `Ctrl+E` → «Как по умолчанию» → «Сохранить» |

## 🧩 Редактор оболочки

<p align="center"><img src="docs/editor.jpg" alt="Редактор" width="800"></p>

- **Тащи** элемент — переезжает, **за уголок** — меняется размер, ручка «тёмная подложка» —
  высота тёмной подложки.
- **Клавиши:** стрелки — сдвиг на 1 px (Shift — на 10), `Tab` — следующий элемент, `Delete` — убрать,
  `Ctrl+Z` — шаг назад, `Ctrl+S` — сохранить. «Выйти» с несохранёнными изменениями переспросит.
- **Правый клик — свойства:** действия левой/правой кнопки и колеса (пауза, перемотка, следующее
  видео, скриншот, громкость, скорость, меню, качество… или своя команда mpv), размер, цвет,
  прозрачность, что прятать первым в узком окне, подсказка, растянуть, по центру, удалить.
- **«Оформление»:** цвет (тема), подложка — затемнение снизу, капсула (скруглённая плашка) или без неё,
  толщина и свечение полосы перемотки. У кнопок в свойствах — «Фон кнопки» (круг) и его прозрачность,
  у текста и надписей — «Шрифт». В любом цвете есть «Свой цвет…» — код вида `#33FF66`.
- **«Создать объект»:** готовые кнопки (скриншот, громче/тише, скорость 1.5×, ±30 с, главы, поверх
  окон, качество стрима, открыть файл…), своя кнопка с иконкой из списка, надпись, встроенные элементы,
  **плашка** (скруглённая подложка под группу кнопок), **зона наведения**.
- **«Как по умолчанию»** возвращает скин к его исходному виду (копии лежат в `skins/defaults/`),
  а скин, сделанный через «Новый скин», — к тому, с которого его скопировали.
- **Зоны наведения** — цветные прямоугольники: где мышь вызывает нижнюю панель, верхнюю (кнопки окна)
  и громкость. Их можно двигать, растягивать и удалять (удалённая зона больше не срабатывает,
  вернуть — «Создать объект» → «Вернуть стандартную зону»). Свою зону создай в «Создать объект»,
  потом у кнопки в свойствах выбери «Появляется в зоне» — кнопка будет появляться сама по себе,
  когда мышь в этой зоне, без остальной панели.
- Положение считается от левого края, центра или правого края окна — это выбирается само,
  поэтому панель правильно растягивается при любом размере окна.

<details>
<summary><b>⌨️ Горячие клавиши</b></summary>

| Клавиша | Действие |
|---|---|
| Правый клик, `Menu` | главное меню |
| Двойной клик | полный экран |
| `Ctrl+E` | редактор оболочки |
| `Alt+Q` | качество стрима / онлайн-видео |
| `Ctrl+O` / `Ctrl+H` | открыть файл / недавние |
| `Alt+S`, `Alt+A`, `Alt+P`, `Alt+C` | субтитры, аудио, плейлист, главы |
| `Alt+D` | аудиоустройство |
| `Ctrl+P` | картинка в картинке |
| `←` `→` / `↑` `↓` / колесо | перемотка 5 с / громкость |

Основные клавиши работают и в русской раскладке. Все привязки — в `input.conf`.
</details>

<details>
<summary><b>⚙️ Настройки</b></summary>

Всё в `script-opts/hybrid.conf` (с комментариями): тема, шаг скорости и громкости, где громкость,
вид значка паузы, размер «картинки в картинке» и т.д. Полный список — в начале
`scripts/hybrid/main.lua` (таблица `user_opts`).

- `theme=prism` — фирменная тема; есть ещё `orange`, `blue`, `purple`, `green`, `red`, `pink`.
- `layout=skin` — панель из скина (`skins/*.json`), `skin=standard` — скин по умолчанию.
- `layout=default` — классическая раскладка без редактора: кнопки включаются строками
  `menu_button`, `shuffle_button`…, ширина линейки — `speed_ruler_width`.
- `click_pause=yes` — пауза по одиночному клику (в этом конфиге выключена).

Внутри скрипт называется `hybrid` (папка `scripts/hybrid`, привязки `script-binding hybrid/...`) —
так сложилось исторически, на работу это не влияет.
</details>

<details>
<summary><b>📁 Что где лежит</b></summary>

| Файл | Что делает |
|---|---|
| `scripts/hybrid/main.lua` | сама панель (на основе ModernZ), раскладки, громкость, линейка, PiP |
| `scripts/hybrid/editor.lua` | редактор оболочки |
| `scripts/hybrid/skin.lua` | формат скинов: чтение, запись, стандартный скин |
| `scripts/hybrid/menu.lua`, `menus.lua` | меню: отрисовка и пункты |
| `skins/*.json` | скины (пишет редактор, руками править не нужно) |
| `scripts/stream-quality.lua` | качество стримов и онлайн-видео |
| `scripts/forget-finished.lua` | досмотренное в следующий раз начинается сначала |
| `scripts/thumbfast.lua` | превью кадров над полосой |
| `scripts/sponsorblock*` | SponsorBlock |
| `script-opts/*.conf`, `input.conf`, `mpv.conf` | настройки скриптов, клавиши, настройки mpv |
</details>

## ❓ Частые вопросы

**Две панели сразу / панель не появляется.** В папке `scripts` осталась другая оболочка (uosc,
ModernZ, osc.lua) — убери её. На Windows mpv читает настройки и из папки рядом с `mpv.exe` — проверь обе.

**Не меняется качество стрима.** Для эфиров Twitch/Kick нужен установленный streamlink, для роликов —
yt-dlp. Пункт «Качество» появляется только у стримов и видео по ссылке.

**Сломал панель в редакторе.** `Ctrl+E` → «Как по умолчанию» → «Сохранить». Или меню → «Скины» →
«Стандарт».

**Иконки показываются квадратиками.** Не скопировалась папка `fonts` — положи её рядом со `scripts`.
